# Work-Schedule-Handler-
A role-based schedule handling application designed for workplace environments where management can create and manage employee work schedules, while general workers can securely view only their assigned schedules. The system uses employee ID–based authentication and enforces access control to ensure privacy and data security.


## Project Documentation
- Architecture blueprint: `docs/architecture.md`
- MVP requirements: `docs/requirements.md`


## Quick Start
1. Set environment variables (`PORT`, `MONGODB_URI`, `JWT_SECRET`) as needed.
2. Start the API: `npm start`.
3. Run tests: `npm test`.
4. Seed demo data: `npm run seed`.
5. Run syntax lint: `npm run lint`.
